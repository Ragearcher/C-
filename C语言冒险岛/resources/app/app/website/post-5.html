类型注解到底值不值得写

2026-08-28 阅读 3.2k Python工程实践

Python 的类型注解不参与运行，写错了也不会报错。那还有必要写吗？

有必要，但收益不在运行时，而在你半年后回来看自己的代码的时候。

什么时候收益最大

函数参数和返回值、以及跨模块传递的数据结构 —— 这两处写上类型，编辑器就能帮你抓掉相当一部分低级错误。

函数体内部的小变量，就随缘吧，不必强求。
