知识点大改版：59 关讲解全部按教材重写

## 一、每一关的知识点讲解都重写了

以前的讲解只有一两句话，只够知道「这行代码干什么」，学不到「为什么要这样写」。
这次按 C 语言教材（数据类型 → 运算符 → 控制结构 → 数组 → 函数 → 指针 → 结构体与文件）
的完整脉络，把**基础篇 10 章 38 关 + 进阶篇 7 章 21 关，共 59 关**的讲解全部重写。

每关现在都是同一套「教材式」结构：

- **概念引入**：这个知识点是什么、为什么需要它。
- **语法格式**：完整规范的写法，配可运行的代码示例。
- **要点清单**：逐条列出规则，比如 `int` 的取值范围、下标从 0 开始、
  `%` 只能用于整数、`&&` 会短路求值。
- **教材补充**（蓝框）：课本里会考但容易被略过的细节，如溢出、
  IEEE 754 精度、`strlen` 与 `sizeof` 的区别。
- **易错点**（橙框）：新手最常踩的坑，如把 `==` 写成 `=`、
  漏写 `&`、数组越界、`else` 的悬空配对。
- **本关任务**（绿框）：本关要完成什么。

平均每关讲解从约 250 字扩到约 1300 字，并新增了**对照表**（如 `printf`
格式符一览、转义字符表、运算符优先级表、`rand()` 区间公式）和小节标题，
排版更像一本可查阅的电子教材。

### 几处典型加深

- **`int` / `float` / `char`**：补上字节数、取值范围、有效数字位数、
  ASCII 码值（`'A'`=65、`'a'`=97、`'0'`=48），并说明 `char` 本质是小整数。
- **整数除法**：讲清「向零截断」，并给出 `17 / 5` 得 3、`17 / 5.0` 得 3.4 的对比。
- **指针**：从「地址」讲起，说明 `&` 与 `*` 的双重含义、指针算术
  （`nums + 1` 是挪一个元素而不是一个字节），以及为什么 `swap` 必须传地址。
- **字符串**：讲清 `'\0'` 结束标志、`char a[]="ab"` 与 `char b[]={'a','b'}` 的区别、
  UTF-8 下汉字占 3 字节。
- **动态内存**：补上 `malloc` 后判 `NULL`、`free` 后置空、
  内存泄漏与悬空指针的区别。
- **期末复习章（r1–r9）**：改成「考点定位 + 必记结论表 + 高频要点 + 典型代码
  + 易错点」的复习体例。
