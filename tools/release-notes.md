判题更准 + 自动更新更稳

## 一、判题只认答案，不再因为写法不同而误判

以前是「输出必须一字不差」，很多明明做对了的同学被卡住。现在只要答案对就算过：

- **忽略空白差异**：行尾多余空格、多余空行、缩进、换行位置不同，都算对。
- **忽略全角/半角差异**：中文输入法打出来的全角空格、全角标点，自动按半角比对。
- **数字按数值比较**：`3.50` 与 `3.5`、`120.0` 与 `120` 视为同一个答案。
- **容忍多余的提示文字**：答案夹在 `计算结果如下：` 之类的提示语中间，照样判过。
- **不再看退出码**：`void main()`、`return 1` 这类写法不会再把正确答案判错。
- **项目题放宽**：只要能编译、能跑完、确实有输出，就算完成。
- 判过时会显示「通过 · 已忽略格式差异」，让你知道是写法不同而不是答案有问题。

同时保留了必要底线，避免把错答案判成对：画图形题的缩进算内容、数字个数必须一致、
`9 8` 不会被当成 `9` 的正确答案。

## 二、自动更新链路全面加固

- **下载前先验包**：压缩包下载完先只读检查一遍（版本号、主程序、目录结构、
  中文文件名编码），不合格直接报错，**游戏不会退出、文件一个都不动**。
  这条从根上掐掉了「更新失败 → 重启 → 又提示更新」的死循环。
- **下载完整性校验**：字节数和服务器声明、线上记录对不上就换线路重下，
  不会再拿着半个包去覆盖。
- **线路记忆**：上次哪条加速线路能用就优先用它，省掉每次先等坏镜像超时的十几秒。
- **下载停滞保护**：30 秒没有任何数据就自动换线路，进度条不会永远卡住。
- **按进程号精确等待退出**：不再死等固定 4 秒，而是等游戏主进程真的退出，
  最多等 30 秒后才强制结束，避免文件被占用导致覆盖失败。
- **更新前自动备份、失败自动回滚**：覆盖 `resources/app` 前先备份，
  回读校验发现没覆盖成功就自动还原，保证游戏始终能打开。
- **检查更新加缓存**：5 分钟内重复点不再发网络请求，手动点仍然强制刷新。
- 进度条新增实时速度显示（MB/s）。

## 三、其他

- 更新包内所有中文文件名统一带 UTF-8 标记，避免 Windows 解压出乱码。
- 网页版的更新提示地址改为真实仓库地址。

## 如果你装的是 v1.0.1

直接打开游戏点右上角 🔄 检查更新即可，会自动升级到 v1.0.2。
